# Budget Tracker

This project is a polished, responsive budget tracker landing page that is ready to be published online. It includes a clear browser title, a custom favicon, and social-sharing metadata so it looks professional when shared.

## What has been built so far

The site currently includes:

- a clean hero section and dashboard-style summary cards
- a transaction form with category selection
- a recent-transactions list with a polished visual layout
- a custom favicon and browser page title
- Open Graph and Twitter metadata for better link previews

## What is coming next

JavaScript functionality for real budget calculations and dynamic transaction handling will be added next week.

## How to view locally

Open the project folder and launch the site by opening the index.html file in a browser, or run a simple local server from the project folder.

## GitHub Pages

This project is designed to be published as a static site using GitHub Pages. After pushing the files to GitHub, enable Pages in the repository settings and publish the site from the main branch.

## Feedback
